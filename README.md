# BRASIL LIFE

Jogo de mundo aberto em Santa Aurora, instalável no iPhone como app (PWA).

**Instalar:** abra https://kelsonpineiromarques0921-tech.github.io/Brasil-lite-jogo/ no Safari do iPhone → Compartilhar → **Adicionar à Tela de Início**.

As atualizações chegam sozinhas: o app baixa a versão nova em segundo plano e aplica ao reiniciar o jogo.
